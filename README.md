# 원자재·매크로 모니터

구리·원유·금 등 선물 시세와 주가지수·환율·미국 금리를 한 화면에 모으고,
가격 움직임을 매크로 관점(예: 구리 급락 → 중국 산업수요 둔화 가능성)으로 해석해 주는 개인용 대시보드입니다.

## 핸드폰으로 보기 (PC 없이, 무료)
GitHub 저장소에 올리면 GitHub Actions가 15분마다 시세를 받아 GitHub Pages로 배포합니다.
1. 이 폴더 전체를 GitHub 저장소(Public)에 올리기
2. 저장소 Settings → Pages → Source 를 **GitHub Actions** 로 선택
3. Actions 탭에서 "시세 갱신 및 배포"를 한 번 수동 실행(Run workflow)
4. 핸드폰에서 `https://<아이디>.github.io/<저장소이름>/` 열고 → 공유 → **홈 화면에 추가**

참고: 저장소에 60일간 아무 변경이 없으면 GitHub이 예약 실행을 멈춥니다. 그때는 Actions 탭에서 다시 켜면 됩니다.

## PC에서 실행하기 (1분)
1. Node.js 18 이상 설치: https://nodejs.org (LTS 버전)
2. 이 폴더에서 터미널을 열고:
   ```
   node server.js
   ```
   - Mac: `start-mac.command` 더블클릭
   - Windows: `start-windows.bat` 더블클릭
3. 브라우저에서 http://localhost:8787 열기

설치할 패키지는 없습니다. 서버를 끄면(Ctrl+C) 화면은 데모 데이터로 바뀝니다.

## 구성
- `server.js` : Yahoo Finance 공개 시세를 받아오는 작은 로컬 서버 (60초 캐시)
- `public/index.html` : 대시보드 화면 + 인사이트 규칙 엔진 (모든 로직이 이 파일 안에 있음)

## 데이터
- 무료 Yahoo Finance 시세, 거래소별로 약 10~20분 지연. 선물은 최근월 연속 계약.
- 종목 추가/변경: `index.html` 의 `INSTR` 목록에 `['그룹','심볼','이름','단위']` 한 줄 추가.

## 인사이트 규칙 (요약)
| 신호 | 판정 | 해석 |
|---|---|---|
| 구리 급락 | 1일/1주 움직임이 평소 변동폭의 2배 이상, 또는 1주 −5% | 중국 제조·건설 수요 둔화 가능성. 호주달러·상하이·항셍·위안·알루미늄 동반 여부로 근거 강도 판단, 달러 강세·재고 등 다른 해석도 표시 |
| 구리/금 비율 vs 10년물 | 1개월 ±5% | 성장 기대 약화/리플레이션, 금리와 엇갈리면 인플레·재정 요인 |
| 원유 급등/급락 | 2σ 또는 1주 ±8% | 공급·지정학 vs 수요, 한국 무역수지·원화 영향 |
| 금 강세 | 2σ 또는 1개월 +6% | 금리 인하 기대 vs 지정학·중앙은행 매입 |
| 달러·원화 | 달러인덱스 1개월 ±3%, 원/달러 1,400원 이상 등 | 원자재·신흥국 압박, 한국 고유 요인 구분 |
| VIX | 20/30 이상 | 경계/공포 |
| 장단기 금리차 | 역전, 역전 해소 | 침체 선행 신호 |
| 복합 | 중국 스트레스, 위험회피, 스태그플레이션, 리플레이션, 달러 주도 원자재 하락 | 여러 자산이 같은 방향을 가리킬 때 신뢰도 상승 |

해석은 자동 생성된 '신호'이며 투자 조언이 아닙니다.
